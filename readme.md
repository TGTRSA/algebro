# Backend
The backend is divivded into subfolders of desktop (intially for testing), android and ios (not yet developed for). It can be found in assets/backend. It will contain the local server side logic for progress tracking and the like.

# Questions folder
* This contains a set of topics with subfolder of varying levels within them are the json files that contain all the questions meant to be answered by a client which are divided into "techniques".

## Topics
These are simply the various modules within math (calculus, algebra, trignonometry, analytical geometry etc).

## Subtopics
These I declare to be the categories of learned information within each topic.
* Algebra: 
    - Exponents
    - Terms
    - Polynomials
    - Factoring 
* Calculus:
    - Derivation
    - Integration
    - Limits

And so on and so forth.

## Techniques
In regard to this the idea is to base each math question with an objective to understand math in (simplification, expansion, manipulation) to create a clearer picture of the problem-solving, critical thinking, lexical and analytic understanding of math and development of logic.

# Progress tracking system
Through some mathematical means we will decide on when exactly a threshold for a level has been reached for each tehcnique not for each subtopic necessarily.
